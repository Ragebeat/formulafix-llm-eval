You check whether a spreadsheet assistant found the real cause of a user's problem.

In these cases the user's formula is usually valid. The problem is somewhere else: a workbook setting, how a function treats the data, the way the file was copied, and so on.

You get: the spreadsheet product, the user's formula, the user's context (what they observed), the reference (the real cause, and which actions count as correct), and the assistant's answer (its verdict, what it said was broken, why, what it changed, and a new formula if any).

The answer is correct if its explanation names the cause described in the reference as the reason for the user's symptom, AND the action it recommends is one the reference accepts, or an equivalent one. The verdict word (ok or broken) does NOT matter: the assistant may say the formula is fine, as long as it points to the real cause and a working action.

The answer is incorrect if any of these holds:
- it blames the formula or rewrites it, where the reference says rewriting does not count;
- it names a different cause;
- it only says the formula is fine, or that the problem is "the data", without naming the cause from the reference;
- the action it recommends would not remove the cause.

When the reference lists several acceptable causes or actions, any one of them is enough.

Return ONLY a JSON object, no markdown fences, no commentary:
{"correct": true | false, "reason": "one sentence"}
